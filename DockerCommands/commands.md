🐳 Docker Commands Cheat Sheet

A practical reference for the Docker commands used in the EazyBytes project.

📦 Docker Images

Commands for building, viewing, inspecting, removing, pushing, and pulling Docker images.

Command

Description

docker build . -t eazybytes/accounts:s4

Build a Docker image from the Dockerfile in the current directory and tag it as eazybytes/accounts:s4.

docker images

List all Docker images available locally.

docker image inspect image-id

Display detailed information about a specific image.

docker image rm image-id

Remove one or more Docker images.

docker image push docker.io/eazybytes/accounts:s4

Push an image/repository to a Docker registry.

docker image pull docker.io/eazybytes/accounts:s4

Pull an image/repository from a Docker registry.

🔨 Build an Image

docker build . -t eazybytes/accounts:s4

What it does:
Builds an image using the Dockerfile in the current directory and assigns the tag eazybytes/accounts:s4.

🚀 Docker Containers

Commands for creating, starting, stopping, restarting, inspecting, and deleting containers.

Command

Description

docker run -p 8080:8080 eazybytes/accounts:s4

Create and start a container from the specified image, mapping port 8080 on the host to port 8080 in the container.

docker ps

Show currently running containers.

docker ps -a

Show all containers, including running and stopped containers.

docker container start container-id

Start one or more stopped containers.

docker container pause container-id

Pause all processes inside one or more containers.

docker container unpause container-id

Resume paused processes inside one or more containers.

docker container stop container-id

Gracefully stop one or more running containers.

docker container kill container-id

Immediately terminate one or more running containers.

docker container restart container-id

Restart one or more containers.

docker container inspect container-id

Display detailed information about a container.

docker container logs container-id

Display the logs generated by a container.

docker container logs -f container-id

Follow the container logs in real time.

docker container rm container-id

Remove one or more containers.

docker container prune

Remove all stopped containers.

▶️ Run a Container

docker run -p 8080:8080 eazybytes/accounts:s4

Host:8080  ───────►  Container:8080

🧩 Docker Compose

Docker Compose lets you define and manage multiple related containers using a Compose file.

Command

Description

docker compose up

Create and start containers defined in the Docker Compose file.

docker compose down

Stop and remove containers, networks, volumes, and other resources created by docker compose up.

docker compose start

Start existing containers without recreating them.

docker compose stop

Stop running containers without removing them.

Common Workflow

docker compose up

Start your application stack.

docker compose stop

Temporarily stop the running containers.

docker compose start

Start the previously created containers again.

docker compose down

Stop and remove the Compose resources.

🗄️ MySQL Container

Create a MySQL database container for the Accounts service:

docker run \
  -p 3306:3306 \
  --name accountsdb \
  -e MYSQL_ROOT_PASSWORD=root \
  -e MYSQL_DATABASE=accountsdb \
  -d mysql

Configuration

Option

Purpose

-p 3306:3306

Maps MySQL's default port from the container to the host.

--name accountsdb

Names the container accountsdb.

-e MYSQL_ROOT_PASSWORD=root

Sets the MySQL root password.

-e MYSQL_DATABASE=accountsdb

Creates the accountsdb database.

-d

Runs the container in detached/background mode.

mysql

Uses the MySQL Docker image.

🔐 Keycloak Container

Create a Keycloak container in development mode:

docker run \
  -p 8080:8080 \
  -e KEYCLOAK_ADMIN=admin \
  -e KEYCLOAK_ADMIN_PASSWORD=admin \
  quay.io/keycloak/keycloak:22.0.3 \
  start-dev

Configuration

Option

Purpose

-p 8080:8080

Maps Keycloak's port 8080 to the host.

-e KEYCLOAK_ADMIN=admin

Sets the initial Keycloak admin username.

-e KEYCLOAK_ADMIN_PASSWORD=admin

Sets the initial Keycloak admin password.

quay.io/keycloak/keycloak:22.0.3

Uses Keycloak version 22.0.3.

start-dev

Starts Keycloak in development mode.

⚠️ Security note: admin / admin is suitable only for local development. Use strong credentials in real environments.
